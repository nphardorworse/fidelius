# Security

If you think Fidelius or `accio` lets a key out in a way it shouldn't, please report it privately: [open a private report](https://github.com/nphardorworse/fidelius/security/advisories/new). That includes new ways around one of the limits listed in the README. If you're not sure, report it anyway.

Include the Fidelius version (Fidelius > About Fidelius), your macOS version, and the steps. Use fake keys in any example. Never send a real key or a real `.env`.
